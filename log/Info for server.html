ZL3TOM SERVER QUICK GUIDE

SSH, Backup & Website Update

A simple reference for connecting to the Ubuntu server, creating a safe backup, and updating the ZL3TOM website.

1. SSH into the server

Open PowerShell or Windows Terminal on your computer and run:

ssh -i "C:\Users\thoma\Documents\GitHub\zl3tom\zl3tom.github.io\log\ssh-key-2026-01-05.key" ubuntu@152.67.121.60

If Windows asks whether you trust the host the first time, type:

yes
Keep the SSH private key file private. Do not upload the .key file to a public GitHub repository.

2. Create a new website backup

Your live site is:

/home/ubuntu/zl3tom-site

Your backup folder is:

/backup/zl3tom/

Create the backup folder if needed:

sudo mkdir -p /backup/zl3tom
sudo chown ubuntu:ubuntu /backup/zl3tom

Create a fresh full backup:

cd /home/ubuntu
tar -czf /backup/zl3tom/zl3tom-site-$(date +%Y-%m-%d-%H%M).tar.gz zl3tom-site

Check the backup exists:

ls -lh /backup/zl3tom/

Verify the newest backup:

LATEST=$(ls -t /backup/zl3tom/zl3tom-site-*.tar.gz | head -1)
tar -tzf "$LATEST" > /dev/null && echo "BACKUP OK: $LATEST"
Do the backup and confirm you see BACKUP OK before updating the website.

3. Delete an old backup

First list the backups:

ls -lh /backup/zl3tom/

Then delete only the old backup you no longer want:

rm /backup/zl3tom/OLD-BACKUP-FILENAME.tar.gz

Example:

rm /backup/zl3tom/zl3tom-site-2026-09-01-1200.tar.gz
Safer order: create the new backup first, verify it, then remove the older backup.

4. Update the ZL3TOM website

After your updated files have been pushed to GitHub, run these commands on the server:

cd /home/ubuntu/zl3tom-site
git pull --ff-only
npm ci
npm run build
npm run check
pm2 restart zl3tom --update-env
pm2 save

The important part is that:

  • git pull --ff-only downloads the latest GitHub version.
  • npm ci installs the required packages.
  • npm run build rebuilds the website.
  • npm run check checks the site before restarting it.
  • pm2 restart zl3tom --update-env restarts the live website.
  • pm2 save saves the PM2 process configuration.

Recommended full routine

For a normal website update, use this order:

  1. SSH into the server.
  2. Create a new backup.
  3. Verify the backup says BACKUP OK.
  4. Update the website from GitHub.
  5. Make sure npm run check passes.
  6. Restart PM2.
  7. Open zl3tom.com and check the site.
  8. Only then remove any old backup you no longer need.
